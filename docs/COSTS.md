# تقدير تكلفة التشغيل

> الأسعار من ملخصات منشورة في 2026 لأسعار Render (لم أستطع فتح صفحة الأسعار الرسمية مباشرة من بيئة العمل). **تحقق من render.com/pricing قبل الاشتراك.** الدولار ≈ 3.75 ريال.

## ما الذي لا يكلف شيئًا
| البند | التكلفة | السبب |
|---|---|---|
| إشعارات الويب (أندرويد + آيفون من الشاشة الرئيسية) | 0 | خدمات FCM و Apple Web Push مجانية ولا تحتاج حسابًا |
| APNs (للـ App Clip) | 0 | مجاني ضمن عضوية المطوّر |
| SMS / واتساب | 0 | غير مستخدم إطلاقًا |
| رموز QR، الطباعة | 0 | تُولَّد داخل النظام |
| شهادة HTTPS | 0 | تلقائية من Render |

## الاستضافة (تكلفة شهرية متكررة)
| السيناريو | الافتراضات | المكونات | التقدير الشهري |
|---|---|---|---|
| **التجربة / محل واحد** (الموصى به الآن) | حتى ~500 طلب/يوم، 1–3 موظفين، شاشة واحدة | Render Web Starter ‏(7$) + Postgres Basic‑256mb ‏(6$) + تخزين ~1GB (~0.30$) | **≈ 13.3$ (≈ 50 ريال)** |
| 5–10 فروع | ~3,000 طلب/يوم، ~300 صفحة عميل مفتوحة بالتزامن | Web Standard ‏(25$) + Postgres Basic‑1gb ‏(19$) + تخزين ~2GB | **≈ 45$ (≈ 170 ريال)** |
| أكبر من ذلك | عدة نسخ خادم | يتطلب تفعيل ناقل أحداث مشترك (PostgreSQL LISTEN/NOTIFY) — البنية جاهزة لذلك لكنه غير مفعّل الآن | يُقدَّر عند الحاجة |

**حساب الحجم:** كل طلب مع سجله وأجهزته ≈ 3–5 كيلوبايت. 500 طلب/يوم × 90 يوم احتفاظ ≈ 45 ألف طلب ≈ 200MB. نقل البيانات: فتح صفحة العميل ≈ 150KB أول مرة (الخط مخزّن بعدها) ← 500 × 30 يومًا ≈ 2–3GB شهريًا، ضمن الحصة المضمنة عادة.

**لماذا ليس مجانيًا؟** الخطة المجانية تنام بعد 15 دقيقة خمول (أول عميل بعدها ينتظر ~دقيقة)، والقاعدة المجانية مؤقتة بلا نسخ احتياطي — غير مقبول لنظام نداء.

## خلاصة للمستثمر
- **التجربة الحالية: ≈ 50 ريالًا شهريًا** بلا أي رسوم لكل رسالة، وبلا شراء أجهزة بيجر أو صيانتها أو استبدال المفقود منها.
- التكلفة الحدّية لكل طلب ≈ صفر (لا SMS).
- التوسع لـ 10 فروع ≈ 170 ريال شهريًا قبل أي تحسين.
