- النقر المتكرر السريع على «طلب جديد» أثناء انشغال الزر ← طلب واحد. ✅
- **انقطاع الإنترنت أثناء الإنشاء** ← رسالة خطأ ولا نجاح كاذب ولا طلب؛ بعد العودة ← طلب واحد. ✅
- مؤشر الاتصال يتحول عند الانقطاع ويعود تلقائيًا. ✅
- موظفان: ما ينشئه أحدهما يظهر عند الآخر لحظيًا؛ تعارض «تسليم» على نسخة قديمة ← رسالة «تغيّر هذا الطلب من جهاز آخر» دون حالة متضاربة. ✅
- إعادة تحميل اللوحة وصفحة العميل؛ فتح الرابط مرتين/في تبويبين ← نفس الجهاز يُحسب مرة. ✅
- متابعة من جهاز ثانٍ ← كلاهما يرى «جاهز» ويُثبَت الظهور. ✅
- العميل يفقد الاتصال ← رسالة ← يُسلَّم الطلب أثناء انقطاعه ← عند العودة تظهر «تم الاستلام». ✅
- إعادة النداء معطلة مع عد تنازلي. ✅ — إلغاء يظهر للعميل لحظيًا. ✅
- أحجام 360×640، 390×844، 768×1024، 1024×600: لا تمرير أفقي، وكل الأزرار ≥ 44px. ✅
- التابلت عموديًا: الرمز كامل داخل الشاشة؛ إلغاء الاقتران يعيدها لصفحة الاقتران لحظيًا. ✅ — تسجيل الخروج. ✅
