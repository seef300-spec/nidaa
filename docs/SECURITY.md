# الأمان والخصوصية

## الأدوار والصلاحيات (تُفرض في الخادم في كل طلب)
| الدور | كيف يُعرَّف | ما يستطيعه |
|---|---|---|
| المالك | جلسة بكوكي `HttpOnly; Secure; SameSite=Strict` | كل شيء في فرعه/محله: الإعدادات، الموظفون، الشاشات، مفاتيح API |
| الموظف | جلسة | الطلبات فقط (إنشاء/نداء/تسليم/إلغاء/بحث/طباعة) في الفروع المرتبط بها |
| شاشة العرض | رمز جهاز طويل (يُخزَّن مُجزّأً SHA‑256) بعد اقتران يُدخل رمزه المالك | قراءة الطلب المعروض حاليًا لفرعها فقط: الرقم والرابط و QR — بلا ملاحظات أو أرقام فواتير أو معرّفات داخلية |
| العميل | رمز عشوائي 144 بت في الرابط | متابعة طلب واحد: الحالة، تفعيل التنبيه، «أنا في الطريق» |
| التكامل (الكاشير) | مفتاح `nd_xxxxxxxx_…` (مُجزّأ) بصلاحيات `orders:read` / `orders:write` | طلبات فرع واحد فقط |

- إخفاء الأزرار ليس حماية: كل مسار `/api/staff/*` و `/api/owner/*` يتحقق من الجلسة والدور وانتماء الطلب للفرع (`WHERE branch_id = …`).
- محاولة الوصول لطلب فرع آخر تُعيد 404 (لا تكشف وجوده).
- إيقاف موظف أو تغيير كلمة مروره يُنهي جلساته فورًا؛ إلغاء اقتران شاشة يقطعها فورًا (وتعود لصفحة الاقتران لحظيًا).

## الحماية
- **CSRF**: كل تعديل بالكوكيز يتطلب ترويسة `X-Nidaa: 1` (لا يمكن لموقع آخر إرسالها دون CORS — وCORS غير مفعّل) + فحص `Origin` + `SameSite=Strict`.
- **XSS**: سياسة CSP صارمة (`script-src 'self'` بلا inline)، وكل النصوص تُدرج عبر `textContent`. الشعار يقبل PNG/JPEG/WebP فقط بفحص البايتات (لا SVG).
- **كلمات المرور**: scrypt مع ملح؛ رسالة خطأ موحدة؛ قفل 15 دقيقة بعد 8 محاولات؛ تحديد معدل لكل IP واسم مستخدم.
- **تحديد المعدل**: عام لكل IP، ومخصص للدخول والإنشاء والاقتران والتنبيه التجريبي، ومتتبع للرموز الخاطئة (منع التخمين).
- **SSRF**: الخادم لا يرسل الإشعارات إلا لخدمات إشعارات معروفة.
- **التكرار والتزامن**: `Idempotency-Key` محفوظ في نفس معاملة العملية؛ قفل صف `FOR UPDATE` + رقم نسخة؛ ترقيم ذري.
- **الترويسات**: HSTS، `X-Frame-Options: DENY`، `Referrer-Policy: no-referrer` (لا يتسرب رابط العميل)، `nosniff`.
- **الأسرار**: كلها في متغيرات البيئة (`SETUP_TOKEN`، مفاتيح APNs). لا أسرار في QR أو كود المتصفح. مفاتيح VAPID الخاصة في قاعدة البيانات (أو البيئة).
- **السجلات**: رموز العملاء مختصرة لأول 4 أحرف، وترويسات Authorization/Cookie محذوفة.

## الخصوصية وتقليل البيانات
- لا اسم، لا رقم جوال، لا بريد، لا موقع للعميل.
- لا يُخزَّن عنوان IP في قاعدة البيانات (يُستخدم في الذاكرة فقط لتحديد المعدل).
- عن جهاز العميل نخزن فقط: معرّفًا عشوائيًا يولّده المتصفح، ونوع المنصة (آيفون/أندرويد/كمبيوتر)، وحالة الإذن.
- **الاحتفاظ والحذف التلقائي**:
  - اشتراكات التنبيه تُغلق عند التسليم/الإلغاء وتُحذف بعد انتهاء مهلة الرابط بيوم.
  - رابط العميل يعمل حتى انتهاء الطلب + 6 ساعات (قابل للتعديل)، ثم «انتهت الصلاحية».
  - الطلبات غير المسلّمة تُغلق تلقائيًا بعد 12 ساعة.
  - الطلبات وسجلاتها تُحذف بعد 90 يومًا (`RETENTION_DAYS`).
  - الجلسات المنتهية، رموز الاقتران، مفاتيح عدم التكرار (48 ساعة)، سجل الأخطاء (30 يومًا).
