# نداء — بيجر رقمي للمقاهي والمطاعم

يستبدل نداء أجهزة البيجر بجوال العميل. الموظف ينشئ الطلب بضغطة، فيظهر رقمه ورمز QR على شاشة أمام العميل. العميل يمسح الرمز ويتابع طلبه بلا تطبيق ولا تسجيل ولا رقم جوال. عند الجاهزية يضغط الموظف «نادِ العميل» فيصل التنبيه، ثم يسجّل التسليم.

> **الحالة: نسخة تجريبية.** المنتج يعمل كاملًا عبر الويب، ومختبر آليًا (45 اختبار خادم و18 اختبار متصفح). **تنبيه الآيفون والشاشة مقفلة لم يُختبر على جهاز حقيقي بعد.** في سفاري العادي هو غير ممكن تقنيًا، والحل الكامل هو App Clip، وكوده جاهز لكنه يحتاج حساب مطوّر آبل. التفاصيل في [docs/NOTIFICATIONS.md](docs/NOTIFICATIONS.md).

## الواجهات
| المسار | لمن | الحماية |
|---|---|---|
| `/staff` | لوحة الموظف: إنشاء الطلبات ونداؤها وتسليمها والبحث | تسجيل دخول (موظف/مالك) |
| `/staff/settings` | الإعداد الأول، المحل والفرع، الموظفون، الشاشات، التنبيهات، API | المالك |
| `/display` | شاشة التابلت أمام العميل | اقتران آمن يمكن إلغاؤه |
| `/o/<رمز>` | صفحة العميل لطلب واحد | رمز عشوائي (144 بت) |
| `/s/<محل>` | صفحة عامة للمحل | عامة |
| `/api/v1/*` | ربط الكاشير مستقبلًا | مفاتيح API بصلاحيات محددة |

## التقنية
Node.js 22 + Fastify، وPostgreSQL كقاعدة مشتركة ودائمة، وتحديث لحظي عبر Server‑Sent Events مع إعادة اتصال ونبضة. واجهات عربية RTL بلا إطار عمل وبلا خطوة بناء. إشعارات الويب عبر Web Push (VAPID) مجانًا، وAPNs لمسار App Clip.

- `src/services/orders.js`: منطق الطلبات والانتقالات ومنع التكرار والتزامن. مستقل عن التصميم وعن مزود الإشعارات.
- `src/services/notify/`: مزودا الإشعارات (Web Push وAPNs) وتسجيل الأدلة.
- `src/routes/`: الواجهات حسب الدور.
- `public/`: الواجهات الأمامية.
- `ios/`: مشروع App Clip وLive Activity.
- `test/`: الاختبارات.

## تشغيل سريع محليًا
```bash
npm ci && createdb nidaa
DATABASE_URL=postgres://localhost/nidaa node src/server.js   # ثم افتح http://localhost:3000/setup
npm test && npm run test:e2e   # تحتاج قاعدتي nidaa_test و nidaa_test2 للمستخدم nidaa
```
